# UNM data library: index

Map of what is in this folder. Read this first, then open only what the task needs. Add a line here whenever a file is added.

Status tags used on every fact:
- `[VERIFIED yyyy-mm-dd, source]` checked against the named source on that date. Usable as written; re-check if older than about a year or if it is a rate, a count or a named person.
- `[CONFIRM]` believed correct but not checked against an official source. Usable in drafts only with a flag for the investigator.
- `[NEEDED]` a known gap. Do not fill it from memory; use a placeholder and ask.

| File | What it holds | State |
|---|---|---|
| `HOW-TO-ADD-DATA.md` | How to add and tag new information | complete |
| `institution/unm-overview.md` | UNM at a glance: designations, structure, names, populations served | seeded, mostly CONFIRM |
| `institution/proposal-logistics.md` | Pre-award office, routing, identifiers, F&A and fringe rates, training requirements | partly verified, several NEEDED |
| `units/health-sciences-center.md` | HSC structure, schools and colleges, research focus areas, compliance offices | seeded |
| `units/unm-hospital.md` | UNM Hospital and the health system: designations, capacity, volumes, clinical data access | seeded, numbers NEEDED |
| `units/college-of-nursing.md` | College of Nursing: programs, research strengths, support for investigators | stub, NEEDED |
| `units/research-centers-and-cores.md` | Centers, institutes, cores, shared equipment, computing | seeded |
| `boilerplate/README.md` | Where reusable approved text goes (Facilities & Resources, environment, commitment letters) | empty, awaiting content |

Folders that do not exist yet but have a planned home: `people/` (biosketch facts, mentors, statisticians), `prior-applications/` (funded examples and summary statements, with permission), `populations/` (clinic volumes, catchment data, community partners).
