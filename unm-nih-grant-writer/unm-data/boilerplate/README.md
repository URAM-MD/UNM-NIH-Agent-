# Boilerplate

Reusable, approved text goes here, one file per piece, for example:

- `facilities-resources-hsc-general.md`
- `facilities-resources-<department>.md`
- `institutional-commitment-k-award-template.md`
- `environment-early-stage-investigator.md`
- `inclusion-and-recruitment-new-mexico.md`
- `data-management-sharing-plan-notes.md`

Start each file with three lines so the skill knows how far to trust it:

```
Written: 2026-03 (from a funded R01, Department of ...)
Approved by: ...
Known stale items: director of X core changed in 2026
```

The skill treats boilerplate as a starting point to tailor to the aims, never as text to paste whole, and checks facts in it against the rest of the library.
